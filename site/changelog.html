版本更新记录

这里只记录公开版本中用户可以感知的变化。每个版本的源码、制品摘要和完整来源证明仍以 GitHub Release 为准。

v0.4.0当前版本2026-08-05
  • 双语产品体验 — 桌面 UI、交互反馈与内置记忆/知识提炼提示词支持简体中文和英文；默认跟随系统，也可在设置中持久化切换。
  • 记忆系统 v2 — 区分人格、工作与项目语境，以作用域、反馈和衰减控制召回；原始用户任务与注入上下文分离，避免标题被记忆前缀污染。
  • 知识系统 v1 — 将体系化成果保存为真实 Markdown 文章，支持主题、标签、来源、草稿、发布、收藏、本机评论与全文搜索。
  • 双图谱与列表 — 记忆和知识首页默认使用圆形图谱，也可切换高密度列表；搜索与筛选在两种视图间保持一致。
  • 提炼策略可控 — 在设置中使用同一 Agent CLI 管理记忆和知识提炼，可修改双语默认提示词，也可一键从已有会话提炼知识。
  • 同源发布 — 桌面端、远程节点、更新元数据、产品站与源码统一发布到 aiutil/agent-os。
