版本更新记录

这里记录 Agent OS 每个公开版本的实际变化。最新安装包见 GitHub Releases，平台与安装方式见 使用指南。

v0.3.82026-07-24
  • 项目筛选更容易使用 — 项目筛选器支持按名称或完整路径即时搜索，列表同时展示项目名和可换行的完整路径，相似目录也能准确区分。
  • 新增项目分组统计 — 统计页新增项目视图，可比较每个项目的会话、提示、Token 和估算费用；点击项目即可查看该项目的每日 Token 使用曲线。
  • 统计数据支持导出 — 总览、Models、项目列表和单项目详情均可导出当前范围与筛选条件下的 CSV，便于在 Excel、Numbers 或脚本中继续分析。
  • 历史数据兼容性 — 缺少工作目录信息的历史会话会稳定归入“未识别项目”，仍可查看详情与趋势并单独导出。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 f10bf3ac96d0，完整 revision 与逐文件摘要见 Release provenance。
v0.3.72026-07-24
  • 图片附件发送前可确认 — 选择、粘贴或拖拽图片后，首屏与已有会话都会显示带文件名和删除按钮的缩略图；普通文件继续使用紧凑胶囊，预览失败也不会影响发送。
  • 定时任务更自然 — 新增每隔 N 分钟或小时的固定间隔计划，手工表单与自然语言创建共用同一调度模型；任务说明从编辑、执行到会话展示都保留原始换行。
  • 消息渠道成为完整控制面 — 飞书、微信、企业微信、Telegram 等已接入渠道可查看和切换自己的会话，创建、查看、编辑、暂停、恢复与确认删除当前工作区任务，并用 /steer 即时修正运行方向。
  • 运行中调整方向 — 对话输入区在 Agent 工作时同时提供调整方向、排队和中断；steer 会安全结束当前回合，在同一会话与原生 Agent 上下文中优先执行修正指令。
  • 安全迁移与可用性 — 设置中可导入导出长期记忆、任务和非敏感 Agent 偏好；API Key、渠道凭据、远程 token、设备私钥和会话正文不会进入备份。
  • 发布重跑更可靠 — 同一源码版本的公开 Release 重跑只复用并校验单个 aggregate manifest，随后继续执行严格的来源、资产集合与 SHA-256 后验。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 c6672f7b1f0b，完整 revision 与逐文件摘要见 Release provenance。
v0.3.52026-07-23
  • 模型列表实时对齐 Agent — Codex、OpenCode、Pi、Cursor 与 Hermes 从各自原生协议、命令或原生缓存读取真实模型；没有可靠枚举接口的 Agent 不再展示猜测列表，可输入 CLI 原生模型 ID。
  • 原生思考级别 — Codex、Claude、OpenCode 与 Pi 的思考级别来自当前模型元数据或当前 CLI 帮助，并通过各 Agent 的原生参数启动；对话和 CLI 终端使用同一选择逻辑。
  • 附件能力精确对齐 — Codex 图片、Pi 文件与图片、Hermes 单图等能力按 Agent 与当前模型取交集；首条消息和已有会话均支持选择、粘贴与拖放，不支持的类型或数量会在启动 Agent 前明确拒绝。
  • 远程协议与可靠性 — 远程 Runtime 返回自身模型目录和结构化附件能力，协议版本升级以阻止旧节点误解析；本地附件到远程节点的上传协议完成前继续安全禁用。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 a1aac29239d0，完整 revision 与逐文件摘要见 Release provenance。
v0.3.42026-07-23
  • Windows 自动更新恢复 — 修复 Windows 10 上从 0.3.0、0.3.2 等版本升级时，进度完成后因只读文件句柄执行 fsync 报 EPERM、无法进入安装步骤的问题。
  • 下载安全门禁保持不变 — 更新包仍须通过 HTTPS、bytes 与 GitHub SHA-256 校验，并在 fsync 成功后才原子提升；真实持久化失败仍会清理临时文件并拒绝安装。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 fcc8e1f78778，完整 revision 与逐文件摘要见 Release provenance。
v0.3.32026-07-23
  • 会话标题来源统一 — 移除 renderer、消息渠道与 runtime 之间的重复改名竞争；聊天任务被 runtime 接受后即以真实 prompt 定稿，用户手动改名不会被后续回合覆盖。
  • CLI 标题更可靠、更安全 — 不再从 PTY 原始按键推断标题，避免 IME 分片、控制序列和敏感命令造成截断或凭据泄漏；native transcript 就绪后再生成任务级标题。
  • 历史标题自动修复 — 识别项目占位名、默认 session 名、注入上下文和序列化 transcript；旧聊天会话从 SQLite 首条真实用户消息幂等恢复，标题中的 password、token、API key 等值会被遮罩。
  • 全界面一致命名 — 会话/CLI 侧栏、工作台和聊天页头、标签页、总览、归档及搜索统一使用共享标题投影；CLI 产品名也统一为 Claude Code、Gemini CLI、Cursor Agent、Hermes Agent 等正式名称。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 0f1d88b0681f，完整 revision 与逐文件摘要见 Release provenance。
v0.3.22026-07-22
  • 执行过程连续流归并 — 同一会话、同一回合内相邻的思考或文本 delta 按原文连续展示，不再把“未完成”等一句话从任意流片段边界拆开。
  • 语义边界保持清晰 — 工具调用、工具结果、权限请求、错误以及跨回合事件仍保持独立过程节点，兼顾可读性与执行审计。
  • 历史记录即时兼容 — 归并发生在共享任务投影层，无需迁移 SQLite 数据；已有任务运行记录打开后即可获得新的连续展示效果。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 87907abec348，完整 revision 与逐文件摘要见 Release provenance。
v0.3.12026-07-22
  • 多平台消息通道 — 飞书改为端到端健康状态；个人微信、企业微信、Telegram 与 WhatsApp 使用独立 transport、接入流程、访问控制和错误状态。
  • 语义定时与任务状态 — 支持“先说今晚 9 点、再补任务内容”的两轮创建；看板卡片、最近更新与详情统一使用工作流状态，确认后不再残留待确认。
  • 产品可运营性 — 新增基础运营 CLI、分步功能引导、关于页版本目录、崩溃诊断与恢复入口，并接入经过隐私白名单约束的 Mixpanel Full 分析。
  • 会话与渲染可靠性 — 收口会话级缓存生命周期，增强流式 Markdown、未闭合代码围栏和严格模式下的稳定渲染，避免异常内容导致空白。
  • 远程节点与同源发布 — 统一受托管设备运行状态与远程 Agent 选择；五个平台继续由原生 runner 构建，并以 provenance、逐文件摘要和 draft 晋升门禁保证源码与制品同源。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 fb3cf5c8b8af，完整 revision 与逐文件摘要见 Release provenance。
v0.3.02026-07-19
  • 五平台消息通道 — 飞书不再把传输连接误报为可用；个人微信、企业微信、Telegram 与 WhatsApp 使用各自独立 transport、接入流程、访问控制和错误状态。
  • 远程节点真实验收 — Runtime protocol 升至 8，主控只有完成协议、真实 PTY 探针和 Agent 发现后才返回 node-adopted；安装与升级以该确认作为成功边界。
  • 一键安装与升级回滚 — 接入命令先验证桌面端锚定的脚本 SHA-256；安装和 agentos-cli update 均使用完整 stage、固定 Node、全文件校验、原子提升与失败恢复。
  • 同源发布事务 — 五个平台由原生 runner 同时生成桌面和节点制品；Release 先进入私有 draft，远端 exact asset set、bytes 与 SHA-256 全部一致后才晋升 Latest。
  • 桌面更新完整性 — 更新器识别 x64、x86_64、amd64 与 arm64、aarch64 架构别名，禁止异构 fallback，并在安装前验证 GitHub asset bytes 与 SHA-256 digest。
  • 构建来源 — 本版本制品绑定 Agent-OS 源码 c172f0fd57cb，完整 revision 与逐文件摘要见 Release provenance。
v0.2.92026-07-18
  • 任务 fallback 可用 — daemon 暂时不可用时，进程内 Runtime 仍可创建、编辑、删除和运行任务，不再提示“当前 Runtime Host 不支持任务调度”。
  • 周期调度互斥 — daemon 与 fallback 共用同一任务仓储，并在切换时严格交接调度器，避免丢任务或重复触发。
  • 桌面单实例 — 重复启动只聚焦已有窗口，不再让不同版本争抢同一个 daemon。
  • 任务详情闭环 — 同一任务集中展示多次运行记录、执行阶段与输出事件，并提供独立“交付物”页签；结果进入 Review 后可打开关联会话，再由用户确认 Done。
  • 飞书消息渠道 — 设置页新增消息渠道中心，飞书机器人通过长连接把 IM 消息转交给本机 Agent OS，并显示连接、消息、闭环与错误状态；其他平台按各自状态展示。
  • 远程托管中心 — 本机可作为主控选择可访问网卡，为不同平台生成节点接入命令，并集中检查节点在线状态、版本兼容与 CLI 可用性。
  • 完整发布验收 — 全量 350 项测试、41 项任务专项测试及安装包真机任务/Cron/单实例验证通过；19 个资产按源码 4a51dc8 重建并完成 SHA-256 核验。
v0.2.82026-07-18
  • Agent 任务看板 — 新增 Todo、In Progress、Review、Done 四列工作流，可创建任务、指定 Runtime Host / Agent CLI / 模型 / 工作区并跟踪执行状态。
  • 完整定时任务系统 — 支持一次性计划与 Cron、时区、错过执行策略、暂停 / 恢复 / 立即运行，并保留独立运行记录。
  • 后台可靠执行 — 计划由 Runtime daemon 持有；关闭桌面窗口后仍可运行，同一工作区自动串行，异常退出任务可恢复为中断状态。
  • 真实会话联动 — 任务执行创建真实 Agent 会话，成功后自动进入 Review，由用户人工确认 Done，也可从任务记录直接打开会话。
  • 重度历史库启动修复 — 存量原生会话回填改为后台执行，并将 transcript 元数据读取并发限制为 8，避免近千份 Claude / Pi 记录同时打开导致窗口迟迟不出现。
  • 远程节点制品修复 — 修复 macOS 节点包中 node-pty 辅助程序缺少执行权限导致的 posix_spawnp failed。
  • 最终制品刷新 — 19 个 Release 资产已按源码提交 0368955 完成最终重建与 SHA-256 核验，桌面首页同步展示最终构建状态。
  • 产品网站内容校准 — 官网按当前左侧导航重写产品能力，新增完整使用指南和 7 个桌面制品直达下载，并明确 CLI 登录、本地数据与模型服务边界。
v0.2.72026-07-16
  • 连续输入不丢失 — 活动回合运行期间新增持久 FIFO 队列，支持附件、取消和 daemon 重启恢复，回合结束后按顺序自动发送。
  • 会话滚动稳定 — 用户上滚阅读历史时不再被流式输出强制拉回底部；新增“跳到最新”，切换会话后恢复正确跟随状态。
  • Claude 输出可靠性 — 兼容 assistant 消息快照，重试过程不再被误判为空闲，并保留最终失败的真实原因。
  • Claude 附件修正 — 本地附件不再误用远端资源 --file，改由路径引用配合 Read 工具读取。
  • 远程节点协议升级 — runtime protocol 升级到 5，节点重连时同步刷新宿主版本与协议版本。
